# Fonts in this folder

Clash Display and Cabinet Grotesk come from [Fontshare](https://www.fontshare.com), under the
[ITF Free Font License](https://www.fontshare.com/licenses/itf-ffl). These are Fontshare's own WOFF2 files, unmodified.

The license lets this site self-host the files. It forbids three things, so keep to them:

- **Do not subset or convert the files.** To change a weight, fetch that weight from Fontshare.
- **Do not copy the files to a public repository,** `toonish-ui` included. This repository is private.
- **Do not hand the files to anyone else.** They get their own copy from Fontshare.

Bangers, the logo and hero face, ships with `toonish-ui` under SIL OFL 1.1.
